# 🛺 রিকশা সিমুলেটর (Vite)

আগের একক HTML ফাইলটাকে Vite প্রজেক্টে ভাগ করা হয়েছে। গেমের আচরণ ও চেহারা একই। three.js এখন npm থেকে আসে (সংস্করণ **0.128.0**, আগের CDN r128 এর হুবহু একই)।

## চালানোর নিয়ম
Node.js 18 বা নতুন লাগবে।

```bash
npm install
npm run dev        # ডেভ সার্ভার, ব্রাউজারে দেখাবে (সাধারণত http://localhost:5173)
npm run build      # dist/ ফোল্ডারে প্রোডাকশন বিল্ড
npm run preview    # বিল্ড করা ভার্সন চালিয়ে দেখো
```

`dist/` ফোল্ডারটা যেকোনো স্ট্যাটিক হোস্টিংয়ে (GitHub Pages, Netlify ইত্যাদি) রাখা যায়।

## ফাইল ভাগ (src/)
| ফাইল | কী আছে |
|---|---|
| `save.js` | সব localStorage: গ্রাফিক্স-মান, টাকা, ইভেন্ট সিড, শিফট/গ্যারেজের অগ্রগতি |
| `core.js` | three.js রেন্ডারার, দৃশ্য, ক্যামেরা, আলো, কয়েকটা শেয়ার্ড হেল্পার (`bn`, `clamp`, `paused`, `HQ`) |
| `world.js` | ম্যাপ, এলাকা, চাঙ্ক তৈরি, স্ট্রিমিং |
| `vehicles.js` | রিকশা, মডেল-বিল্ডার (গাড়ি/বাস/ট্রাক/বাইক/মানুষ), চালানোর অবস্থা |
| `passengers.js` | যাত্রী, ভাড়া, রুট-নেভিগেশন (অবরোধ এড়ানো) |
| `ui.js` | টোস্ট, টাকার HUD, মিনিম্যাপ, বড় ম্যাপ, টাচ বাটন |
| `traffic.js` | NPC গাড়ি, সিগনাল, পথচারী, ট্রাফিক পুলিশ |
| `npc.js` | জীবন্ত NPC |
| `events.js` | রাস্তার ঘটনা (দুর্ঘটনা ৬৫ সেকেন্ড পর মিলিয়ে যায়) |
| `economy.js` | শিফট, লক্ষ্য, গ্যারেজ, আয়-ব্যয় |
| `audio.js` | হর্ন |
| `main.js` | কিবোর্ড ইনপুট, বিরতি, গ্রাফিক্স-মান, ফ্রেম আপডেট ও গেম-লুপ |

## মনে রাখার মতো
- অন্য ফাইল থেকে বদলানো দরকার এমন কয়েকটা ভেরিয়েবল (`money`, `seat`, `trip`, `paused`, `HQ`) এখন ছোট সেটার ফাংশন দিয়ে বদলায় (`setMoney`, `setSeat`, `setTrip`, `setPaused`, `setHQ`)। কারণ ES মডিউলে অন্য ফাইলের ভেরিয়েবলে সরাসরি মান বসানো যায় না।
- ফাইলগুলোর মধ্যে কিছু জায়গায় পারস্পরিক নির্ভরতা আছে (যেমন `passengers` ↔ `ui`)। এগুলো শুধু ফাংশনের ভেতরে ব্যবহার হয়, তাই লোডের ক্রমে সমস্যা হয় না।
- localStorage-এর কী-গুলো আগের মতোই। তবে ঠিকানা (origin) বদলালে (যেমন `localhost:5173`) আগের সেভ পাওয়া যাবে না।
